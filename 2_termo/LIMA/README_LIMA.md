## Tecnologias praticadas

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Estrutura semântica, textos, links, imagens, listas e formulários. |
| CSS3 | Cores, tipografia, espaçamento, layout e apresentação visual. |
| Wireframe e identidade visual | Planejamento da interface antes da implementação. |

Para visualizar uma página, abra o arquivo `.html` no navegador. Preserve os caminhos relativos entre HTML, CSS, JavaScript e imagens. Algumas páginas são versões de exercícios diferentes e foram mantidas para registrar a evolução.
