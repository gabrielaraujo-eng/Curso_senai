AULA 01 — O INÍCIO DE TUDO

Tema:

Como a Internet funciona e onde o HTML entra nessa história.

Objetivos da aula

Ao final da aula o aluno será capaz de:

  • Entender a diferença entre Internet e Web.
  • Compreender o papel do HTML, CSS e JavaScript.
  • Conhecer a profissão de Desenvolvedor Front-end.
  • Identificar páginas HTML reais.
  • Preparar o ambiente de desenvolvimento.
  • Criar seu primeiro arquivo HTML (sem preocupação com estrutura completa).

História da aula

A partir desta aula, todos os alunos passam a fazer parte da DevSolutions, uma software house fictícia.

Na primeira reunião da equipe, eles recebem a notícia de que um novo cliente chegou: a startup ConectaMais, que precisa melhorar sua presença na web. O gerente explica que, antes de colocar a mão no projeto, toda a equipe precisa entender como a Web funciona e qual é o papel de cada tecnologia. Essa narrativa prepara naturalmente o terreno para o estudo de caso previsto no plano de ensino.

Estrutura da aula

🟢 Parte 1 — Quebra-gelo

Pergunta

Quem aqui entrou em algum site hoje?

Pergunta:

  • Quem acessou Instagram?
  • YouTube?
  • Mercado Livre?
  • Netflix?
  • WhatsApp Web?

E agora:

O que todos esses sites têm em comum?

🟢 Parte 2 — Curiosidade

Mostre uma imagem de uma página famosa (Google, YouTube ou Instagram).

Pergunte:

O que existe por trás dessa tela bonita?

Depois pressione F12.

Quando abrir o DevTools diga:

"Parabéns. Vocês acabaram de entrar nos bastidores da Internet."

🟢 Parte 3 — Contando uma história

Em 1991, um cientista chamado Tim Berners-Lee queria facilitar o compartilhamento de documentos entre pesquisadores. A solução criada por ele foi o HTML, a base da World Wide Web.

Em seguida, conecte com o cotidiano:

  • Quando você abre o Nubank, existe HTML.
  • Quando abre o Spotify, existe HTML.
  • Quando compra algo na Amazon, existe HTML.
  • Quando entra no Portal do SENAI, existe HTML.

Conclusão:

A Web inteira conversa em HTML.

Dinâmica 1 — Caça ao HTML

Tempo: 25 minutos

Divida a turma em duplas.

Cada dupla escolhe um site diferente.

A missão é responder:

  • Existe HTML?
  • Existe CSS?
  • Existe JavaScript?
  • Há imagens?
  • Há vídeos?
  • Há formulários?

Explicação principal

Uma casa

HTML é a estrutura.

CSS é a pintura e a decoração.

JavaScript é a eletricidade e a automação.

Depois mostre três exemplos visuais da mesma página:

  • apenas HTML;
  • HTML + CSS;
  • HTML + CSS + JavaScript.

Mão na Massa

Agora sim o VS Code entra em cena.

Os alunos:

  • instalam o VS Code (ou verificam se já está instalado);
  • criam uma pasta chamada AULA1_INTRODUCAO;
  • criam um arquivo chamado INDEX.HTML;
  • escrevem:
Olá, mundo!

Salvam.

Abrem no navegador.

É um momento simples, mas muito simbólico: vocês publicaram a primeira página da carreira.

Missão DevSolutions

O gerente da software house envia a primeira tarefa:

A ConectaMais quer conhecer quem faz parte da equipe.

Cada aluno cria uma página simples contendo:

  • nome;
  • idade;
  • cidade;
  • hobby;
  • sonho profissional.

Desafio

Quem terminar primeiro pode adicionar:

  • uma frase favorita;
  • um filme favorito;
  • um jogo favorito;
  • um livro ou série.

Curiosidades

💡 O Google processa bilhões de pesquisas por dia usando páginas construídas sobre tecnologias da Web.
💡 O HTML não é uma linguagem de programação. É uma linguagem de marcação.
💡 O primeiro site criado ainda está disponível na internet.

Erros comuns

❌ Confundir Internet com Web.

❌ Achar que HTML é programação.

❌ Pensar que HTML "faz cálculos".

❌ Acreditar que HTML funciona sozinho sem um navegador.
