Essa aula é extremamente importante. Na maioria dos cursos, ela é um monte de teoria sobre <html>, <head> e <body>.

Nós não vamos fazer isso.

Vamos fazer o aluno entender POR QUE essas tags existem.

Sprint: 02 - Primeira Entrega para o Cliente

Objetivos

Ao final da aula o aluno será capaz de:

  • Criar a estrutura básica de um documento HTML5.
  • Entender a função de cada elemento principal (<!DOCTYPE>, <html>, <head>, <body>).
  • Criar títulos, metadados e comentários.
  • Utilizar o VS Code com mais autonomia.
  • Compreender como o navegador interpreta um documento HTML.

Curiosidades

Mostre algumas informações que aproximam o conteúdo da realidade:

  • O VS Code completa automaticamente a estrutura HTML quando você digita ! e pressiona Tab.
  • O elemento <title> define o texto exibido na aba do navegador e influencia os resultados dos mecanismos de busca.
  • O atributo lang="pt-BR" ajuda leitores de tela e mecanismos de busca a interpretar corretamente o idioma da página.
