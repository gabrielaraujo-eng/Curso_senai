TRILHA CRUD READ - PROJETO DO ALUNO
Requisitos: Node.js instalado; VS Code ou editor similar.
1. Extraia o ZIP em uma pasta (não edite o ZIP diretamente).
2. Abra a pasta Projeto_Aluno no VS Code.
3. No terminal, rode: node -v
4. Leia maquinas.json e app.js antes de programar.
5. Complete as funções TODO de app.js; não modifique os dados do JSON.
6. Rode: npm start
7. Rode: npm test (é normal falhar antes de implementar as funções).
8. Salve capturas dos resultados, inclusive ID 99.
9. Entregue app.js, relatório individual em PDF e evidências dos testes no Classroom.
Atenção: o gabarito do professor não é destinado aos alunos.
