# Política de segurança

Este é um projeto público de estudo. Se você encontrar uma vulnerabilidade que possa expor dados, credenciais ou usuários, não publique detalhes exploráveis em uma issue aberta.

Envie um relato privado ao mantenedor pelo contato disponível no perfil de Gabriel Araújo, incluindo:

- uma descrição do problema;
- os passos para reproduzi-lo;
- o impacto observado;
- uma sugestão de correção, se tiver.

Não inclua senhas, tokens ou dados pessoais no relato. Como este projeto pode não ter uma equipe de segurança dedicada, o prazo e a possibilidade de correção dependem da disponibilidade do mantenedor.
