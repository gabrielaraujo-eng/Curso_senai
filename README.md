## Conteúdo por termo

### 1º termo — fundamentos

O primeiro termo constrói a base técnica e analítica para o desenvolvimento de sistemas:

- **Lógica de programação:** algoritmos, variáveis, tipos de dados, operadores, condicionais, laços, listas, tuplas, dicionários, funções e boas práticas em Python, além de exercícios em Haskell.
- **Engenharia de requisitos:** requisitos funcionais e não funcionais, elicitação, entrevistas, brainstorming, UML, especificação, validação e prototipação.
- **Sistemas operacionais:** processos, memória, sistemas de arquivos, comandos Windows/Linux, usuários, permissões, pacotes, segurança, logs, firewall e hardening.
- **Arquitetura, redes e IoT:** cabeamento RJ45, ativos e passivos de rede, Arduino, ESP32, sensores, atuadores e comunicação MQTT.

### 2º termo — desenvolvimento

O segundo termo avança para a construção de aplicações e a integração entre interface, servidor e dados:

- **Back-end:** Node.js, programação orientada a objetos, relacionamento entre objetos e materiais de desenvolvimento.
- **Banco de dados:** instalação e configuração, MER, DER, dicionário de dados, DDL, SQL e estruturas físicas, com exemplos como SmartCoffee e Oficina de Veículos.
- **LIMA:** HTML semântico, CSS, tipografia, imagens, favicon, layouts, listas, links, formulários, páginas de suporte e o projeto DevSolutions.
- **Projetos integradores:** imagens, protótipos, páginas HTML, estilos CSS e arquivos de organização do desenvolvimento.

## Como consultar os materiais

Arquivos `.md`, `.py`, `.hs`, `.html`, `.css`, `.js` e `.sql` podem ser abertos diretamente no GitHub ou em um editor de código. Arquivos `.pdf`, `.rtf`, `.docx` e imagens servem como material de apoio e documentação. Para executar códigos, entre na pasta correspondente e siga o README específico; verifique também se o ambiente necessário está instalado.

Alguns nomes preservam a nomenclatura original das aulas. Ao copiar caminhos no terminal, use aspas quando houver espaços, acentos ou caracteres especiais.
