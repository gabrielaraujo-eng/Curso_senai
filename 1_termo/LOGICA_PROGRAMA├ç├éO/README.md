# Lógica de Programação — Python

Este módulo registra a construção da base de programação do curso por meio de conteúdos teóricos, exercícios, projetos pessoais e avaliações.

## Conteúdo estudado

| Etapa | O que foi aprendido |
| --- | --- |
| Fundamentos | Algoritmos, variáveis, tipos (`int`, `float`, `str`, `bool`) e operadores. |
| Entrada e saída | Leitura com `input()` e apresentação de resultados com `print()`. |
| Condições | Uso de `if`, `elif` e `else` para decisões. |
| Repetições | Uso de `for`, `while`, `range()`, `break` e `continue`. |
| Coleções | Listas, tuplas e dicionários. |
| Funções | Criação de rotinas com `def` e retorno com `return`. |
| Código limpo | Nomes significativos, funções pequenas, comentários de contexto e PEP 8. |
| Interfaces gráficas | Tkinter, `ttk`, `pack`, `grid`, `Label`, `Button`, `Entry` e `messagebox`. |

## O que foi realizado

Em [`gabriel/Atividades_complementares/Python/`](./gabriel/Atividades_complementares/Python/) foram praticados cálculos, entrada de dados, condições, fórmulas, testes e raciocínio lógico. Em [`gabriel/Atividades_complementares/Haskell/`](./gabriel/Atividades_complementares/Haskell/) foram exploradas funções, recursão, condições e programação funcional.

Em [`gabriel/PROJETOS/`](./gabriel/PROJETOS/) foram desenvolvidos exercícios maiores, incluindo uma biblioteca, um elevador e um fluxo de cancelamento de compras. Em [`gabriel/Provas/Formativa/`](./gabriel/Provas/Formativa/) estão as listas formativas; as pastas [`Somativa lista 1/`](./gabriel/Provas/Somativa%20lista%201/) e [`Somativa lista 2/`](./gabriel/Provas/Somativa%20lista%202/) concentram as atividades somativas.

## Como executar

Para Python:

```bash
python nome_do_arquivo.py
```

Para Haskell, consulte o [README da pasta de Haskell](./gabriel/Atividades_complementares/Haskell/README.md). Alguns exercícios recebem dados pelo terminal e outros podem abrir uma interface gráfica; execute-os em um ambiente local com suporte a janelas quando necessário.

## Continuidade dos estudos

Ao adicionar uma atividade, mantenha-a na pasta correspondente, use nomes descritivos e registre neste README o objetivo, os conceitos praticados e o caminho do arquivo. Assim, o histórico do aprendizado permanece fácil de consultar.
