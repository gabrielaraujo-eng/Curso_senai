# Atividades Complementares — Lógica de Programação

Esta pasta reúne estudos extras de Gabriel para reforçar lógica, resolução de problemas e fundamentos de programação.

## Caminho de navegação

| Pasta | Conteúdo |
| --- | --- |
| [`Python/`](./Python/) | Exercícios de entrada e saída, cálculos, condições, fórmulas e testes de lógica. |

## O que foi praticado

Os exercícios consolidam variáveis, conversão de tipos, operadores, condicionais, repetições, funções e decomposição de problemas. A prática em mais de uma linguagem ajuda a comparar estilos de programação e fortalecer o raciocínio.
