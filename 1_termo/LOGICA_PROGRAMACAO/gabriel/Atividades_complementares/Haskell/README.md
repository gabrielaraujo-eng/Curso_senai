# Haskell — Estudos e Exercícios

Pasta de exercícios introdutórios em Haskell para praticar programação funcional, funções, recursão, condições, entrada de dados e conversão de tipos.

## Requisitos

Instale o [GHCup](https://www.haskell.org/ghcup/) ou o GHC (Glasgow Haskell Compiler). Verifique a instalação com:

```bash
ghc --version
```

No Windows, configure o PATH de forma permanente quando possível. O comando temporário utilizado foi:

```powershell
$env:Path += ";C:\ghcup\bin;C:\ghcup\ghc\9.6.7\bin"
```

## Como executar

```bash
runghc nome_do_arquivo.hs
```

| Tema | Aplicação |
