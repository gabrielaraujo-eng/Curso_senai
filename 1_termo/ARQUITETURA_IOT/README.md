# Arquitetura de Redes e IoT

Módulo dedicado à infraestrutura de redes, aos dispositivos embarcados e à comunicação entre sensores, atuadores e serviços de Internet das Coisas.

## Conteúdo estudado

| Aula ou assunto | O que foi aprendido |
| --- | --- |
| Ativos de rede | Função de switches, roteadores, pontos de acesso e modems. |
| Passivos de rede | Cabos, racks, patch panels, calhas e conectores como suporte físico da transmissão. |
| Cabeamento | Conector RJ45 e noções de padrões EIA/TIA 568A e 568B. |
| Arduino | Uso de microcontroladores para prototipação e automação. |
| ESP32 | Microcontrolador com Wi-Fi 2,4 GHz e Bluetooth, incluindo comunicação serial e drivers. |
| Sensores | Leitura de grandezas físicas com sensores analógicos e digitais, como LDR, DHT, PIR e ultrassônico. |
| Atuadores | Acionamento de LEDs, buzzers, servomotores e relés. |
| MQTT | Comunicação leve no modelo Publish/Subscribe com broker, tópicos, publicação e inscrição. |

## Resultado do estudo

O módulo relaciona a infraestrutura física da rede ao desenvolvimento de soluções IoT. O fluxo estudado pode ser resumido como **sensor → microcontrolador → broker MQTT → aplicação ou atuador**.
