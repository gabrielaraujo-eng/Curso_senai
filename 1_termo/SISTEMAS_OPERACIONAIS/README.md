# Sistemas Operacionais

Este módulo registra os estudos sobre o software responsável por administrar recursos de hardware e oferecer suporte à execução das aplicações.

## Conteúdo estudado

| Tema | O que foi trabalhado |
| --- | --- |
| Processos e threads | Estados de processos, escalonamento, concorrência e execução de tarefas. |
| Memória | Memória virtual, paginação, segmentação e alocação dinâmica. |
| Arquivos | Diretórios, permissões, metadados, journaling e organização do armazenamento. |
| Entrada e saída | Drivers, interrupções, buffering e spooling. |
| Windows | PowerShell/CMD, processos, serviços, rede, permissões, UAC, Defender e BitLocker. |
| Linux | Bash, processos, `systemctl`, permissões POSIX, `sudo`, `apt`, `ufw` e logs. |
| Segurança | Malware, exploits, menor privilégio, firewall, hardening, atualizações e auditoria. |

## Atividades realizadas

A pasta [`SOP/`](./SOP/) contém folhas de atividades para Windows, atividade complementar, avaliações, relatórios técnicos sobre versões do Windows e sistemas operacionais, além de certificados relacionados a segurança, sustentabilidade e tecnologia. Os arquivos PDF e imagens funcionam como registros das tarefas e materiais de apoio.

## Como consultar

Abra primeiro o material teórico, depois as folhas de atividade e, por fim, os relatórios e avaliações. Para reproduzir comandos, utilize um ambiente Windows ou Linux adequado e confirme o comando antes de executá-lo em um sistema real.
