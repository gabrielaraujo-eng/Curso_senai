# Contribuindo com Curso_senai

Obrigado pelo interesse em contribuir. Este repositório é mantido por Gabriel Lúcio de Araújo e reúne um projeto público de estudo e desenvolvimento.

## Como contribuir

1. Abra uma issue descrevendo a sugestão, o problema ou a melhoria antes de começar uma mudança maior.
2. Crie uma branch a partir de \ com um nome curto e descritivo.
3. Faça uma alteração focada, mantendo o estilo e a tecnologia já usados neste projeto.
4. Teste a mudança localmente e descreva no pull request o que foi verificado.
5. Abra o pull request para a branch \ e aguarde a revisão.

Correções pequenas de documentação e acessibilidade também são bem-vindas. Não inclua senhas, chaves de API, dados pessoais ou arquivos gerados sem necessidade.
